# UI preview

Run `pnpm install --frozen-lockfile`, then `pnpm dev:preview` and open
<http://127.0.0.1:3217/ui-preview>. No account or environment variables are
needed. The command binds to loopback and starts a dedicated development mode.
If file watching fails, use `WATCHPACK_POLLING=true pnpm dev:preview`.
The route is available only in development with `PERMINISTER_UI_PREVIEW=1`.

Select a screen and populated or empty scenario in the toolbar. The gallery uses
fictional `.test` addresses and the application's production components:

| Screens                                                                                         | Coverage                                                                   |
| ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| `overview`, `products`, `members`, `keys`                                                       | Summary, product catalog, organization members and synthetic API keys      |
| `settings`, `activity`, `profile`, `sessions`                                                   | Organization settings, activity, account details and signed-in devices     |
| `product-overview`, `product-people`, `product-access`, `product-roles`                         | Product details, members, permissions and permission sets                  |
| `product-clients`, `client-edit`, `product-keys`, `product-activity`                            | Populated/empty client list, client settings, keys and activity            |
| `product-new`, `product-role-new`, `product-client-new`, `product-invite`, `product-access-new` | Product, permission set, app client, invitation and permission grant forms |
| `key-new`, `organization-new`                                                                   | API key and organization request forms                                     |
| `operations`                                                                                    | Pending organization request and registered account controls               |

Inputs, dropdowns, display controls and confirmation dialogs can be inspected.
Submissions are stopped before component handlers run, and dashboard links do
not navigate. The preview mode also rejects write requests through the
application proxy, including before the page hydrates. Nothing is persisted.
Product website lookup and creation cannot complete. The invitation section
reflects local mail configuration; without mail it shows the unavailable state.

The existing public pages can be opened directly on the same server: `/`,
`/privacy`, `/developers`, `/developers/getting-started`, `/developers/api-keys`,
`/developers/permissions`, `/developers/storage`, `/login`, `/register` and
`/forgot-password`. These are their real routes, not fixtures. Preview mode
rejects writes, but they can still perform reads; use only an isolated local
configuration without real service credentials or data. Never expose this server
to a network. The browser guard is not a security boundary.

Fixtures are in `src/app/ui-preview/fixtures.ts` and the scenario composition is
in `src/app/ui-preview/page.tsx`. Keep fixtures synthetic, avoid data-service
calls, and update the guard and tests when adding interactive components. The
gallery does not yet cover every authenticated page, invitation delivery, successful mutation feedback,
or third-party data. It is a visual development aid, not an authentication bypass
or a substitute for end-to-end tests.

## Route map

The mapping below names each page route and the closest gallery screen. A screen
reuses the page's principal production component(s), but its shell, notices,
navigation context and data are synthetic; it is not a complete route-level
replica. `populated` and `empty` apply only where the corresponding screen has
both fixtures. Buttons and links that would leave the gallery are disabled.

| Application route                                                                                    | Preview or limitation                                                                                                                                                                                                                                                                                   |
| ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/dashboard`                                                                                         | Redirect only: chooses an organization or request history from the authenticated session.                                                                                                                                                                                                               |

API endpoints and action handlers are not gallery pages. Loading files are
transient route fallbacks and are not individually selectable. Successful writes,
email delivery, one-time secrets and OAuth callbacks require real service state
and are deliberately not exercised by this isolated gallery.
